# 《智能涌现》项目说明

> 主题：用可视化的方式，表达**人工智能作为新质生产力的作用和意义**
> 形式：纯前端交互网站（无后端），由 1 条数据叙事和 5 个交互工具页组成，支持日间 / 夜间双主题
> 规模：40 余个交互图表，30 余种可视化形式，30 余组公开数据（数据截至 2026 年 10 月）

---

## 一、全文讲了什么

### 1. 核心论证

网站围绕新质生产力的官方定义展开，再用数据逐项论证 AI 的作用：

> 新质生产力 = 劳动者、劳动资料、劳动对象及其优化组合的跃升，以全要素生产率（TFP）大幅提升为核心标志。

论证分为四步：

1. **AI 同时作用于三要素**，这一点使它区别于以往只作用于单一环节的技术，是一种"通用目的技术"。
2. **技术突破、要素配置、产业升级**这三大催生动力，在 AI 身上都有可以量化的证据。
3. 微观层面，随机对照实验证明 AI 能显著提升效率；宏观层面，它将重塑就业结构和空间格局。
4. 最终的落点是**全要素生产率的跃升与高质量发展**，政策给出了到 2035 年的时间表。

### 3. 五个交互工具页

叙事负责"讲清楚"，工具页负责"用起来"。五个页面分别从结构、历史、个人、企业、数据五个视角深化主题。

| 页面 | 视角 | 怎样表达主题 |
|---|---|---|
| 知识图谱 | 结构 | 把 40 个概念用 72 条关系连成网络。点击任一节点，会高亮它**通往"新质生产力"的因果路径**，例如：大模型 → 劳动资料 → 全要素生产率 → 新质生产力 |
| AI 时光轴 | 历史 | 收录 1943—2025 年 43 个里程碑，与算力曲线联动；按年代统计里程碑数量，可以直观看到技术突破在加速 |
| 岗位诊断 | 劳动者 | 拆解个人工作中被 AI 替代、增强、仍由人主导的部分，按 IMF"暴露度—互补性"框架定位到四个象限 |
| 效益测算 | 企业 | 测算 AI 带来的效率价值、投资回报率和回收期；用敏感性热力图展示"用得好"比"买了工具"更重要 |
| 数据工作台 | 数据 | 全站数据可以检索、出图、下载；"指数对比"把不同量纲的指标统一到同一坐标轴上比较增长速度 |

## 二、使用了哪些技术

| 技术 | 在项目中的用途 | 为什么选它 |
|---|---|---|
| **Svelte 5**（runes 语法） | 页面与组件框架，负责响应式状态和声明式渲染 | 编译型框架，没有虚拟 DOM 开销；`$state` / `$derived` 的细粒度响应，适合"拖动滑块 → 图表实时变化"这类高频交互 |
| **Vite 8** | 开发服务器与构建 | 启动快、热更新快；工具页和 p5.js 按需加载，自动做代码分割 |
| **D3.js 7** | 比例尺、坐标轴、线 / 面积生成器、地理投影、力导向布局、缩放、刷选、层级树、Delaunay 最近点查找 | 数据可视化领域的事实标准，能精细控制每一个图形元素 |
| **d3-sankey** | 就业流向桑基图 | 专门的桑基布局算法 |
| **p5.js 2** | 首屏粒子文字、结语生长网络 | 适合生成艺术与粒子动画，用来做有"情绪"的开场和收尾 |
| **TopoJSON + world-atlas** | 3D 地球的国家边界 | 体积小，可以直接转换为 GeoJSON |
| **阿里云 DataV GeoJSON** | 中国省级地图（含南海诸岛） | 边界数据完整、规范 |
| **Canvas 2D** | 旋转地球、粒子动画 | 每帧大量绘制时性能优于 SVG |
| **SVG** | 绝大多数统计图表 | 矢量清晰，便于交互、做无障碍标注和动画 |
| **View Transitions API** | 日夜主题切换的圆形扩散动画 | 浏览器原生能力，不需要额外的库 |
| **IntersectionObserver** | 滚动叙事分步、图表进入视口时生长、画布离开视口时暂停 | 原生 API，比监听 scroll 事件更省性能 |
| **CSS 自定义属性** | 双主题设计令牌 | 一处定义，全站切换 |

## 三、技术与设计优势

### 1. 表达力：用"交互"讲道理，而不只是"展示"数据

- **会讲故事的图**：千年 GDP 曲线随着滚动缩放，依次聚焦四次技术革命，让观众亲身"走过"历史。
- **可以动手的图**：生产函数模拟器、岗位诊断、效益测算都允许修改参数，让观众自己得出"AI 提升全要素生产率"的结论。
- **有情绪的图**：开场粒子汇聚、结尾网络生长，用生成艺术为理性的数据加上感性的隐喻。
- **会推理的图**：知识图谱用最短路径算法，把任意概念和"新质生产力"之间的因果链条算出来、点亮。

### 2. 可信度：数据有出处，口径有说明

- 每张图都标注了来源。关键数据（Epoch AI 原始 CSV、网信办备案公告附件、OWID 数据等）都核对过原始数据。各省大模型备案数是逐条解析网信办公告附件统计出来的。
- 口径差异如实说明，例如算力在 2024 年前后分别按 FP32 和 FP16 统计、产业规模存在不同统计范围。
- 教学模型（模拟器、岗位系数、效益测算默认值）都明确标注"示意"，不冒充预测。
- 研究结论正反都呈现：除了 AI 提升效率的实验，也展示了 METR 2025 年"资深开发者反而变慢 19%"的反例。

### 3. 工程质量：结构清晰、性能友好、零成本部署

- **四层结构**：数据层 `data/`、图表组件层 `lib/charts/`、章节层 `sections/`、页面层 `pages/`。改数据不需要动图表代码。
- **组件复用**：柱状图、条形图、哑铃图、折线图等通用组件在多个章节和页面中复用。
- **性能**：工具页与体积较大的 p5.js 按需加载；粒子画布离开视口自动暂停；力导向图、时间轴都只在需要时重绘。
- **零后端**：构建后就是静态文件，可以直接部署到 GitHub Pages 等任何静态托管平台。

### 4. 可访问性与色彩科学

- 每张图表都能一键切换为**数据表视图**，保证颜色不是读取数值的唯一途径。
- 两套主题的分类色板都用色觉障碍（CVD）模拟脚本校验过：相邻颜色在红 / 绿色盲视角下仍然可以区分。
- 遵循数据可视化规范：只用单一 y 轴、发散色中点为中性灰、数值大小用单色相渐变、只给关键点加标签。
- 支持键盘操作和"减少动态效果"系统设置，在 1440px 和 390px 宽度下都没有横向溢出。

### 5. 日间 / 夜间双主题

- **夜间**：深空蓝背景，配电光青与紫色，营造沉浸的科技感。**日间**：冷白背景，高对比的墨色文字，标题使用"电光蓝 → 霓虹紫 → 洋红"渐变，追求视觉冲击力。
- 两套主题分别设计，不是简单反色：图表色板、顺序色阶方向、地图与地球底色、粒子配色都各有一套。
- 切换时以点击位置为圆心做圆形扩散动画，所选主题会被记住，刷新时不会闪烁。

## 五、运行方式

```bash
npm install
npm run dev       # 开发模式 http://localhost:5173
npm run build     # 构建到 dist/
npm run preview   # 预览构建结果 http://localhost:4173
```

页面地址：`#/` 数据叙事 · `#/graph` 知识图谱 · `#/timeline` AI 时光轴 · `#/job` 岗位诊断 · `#/roi` 效益测算 · `#/data` 数据工作台

## 六、数据说明与局限

- **主要来源**：国务院政策文件；工信部、国家数据局、国家网信办；CNNIC；中国信通院；Stanford AI Index 2025/2026；Epoch AI；IFR；WIPO；WEF；IMF；IEA；PwC；McKinsey；Maddison Project；以及多篇 AI 生产率实证论文。完整列表见网站页脚。
- **普华永道区域数据**：中国和北美的数值经新闻稿核实，其余区域取自报告中的区域图。
- **麦肯锡行业数据**：只采用了已核实或部分核实的行业。
- **示意模型**：1820 年前的人均 GDP 为早期估算的换算值，图中以虚线表示；生产函数模拟器、岗位诊断的任务系数、效益测算的行业默认值，都是基于文献区间的教学示意模型。
